# SoundCut - 專業線上音訊剪輯與修復工具

SoundCut 是一個基於 React 19 與 TypeScript 開發的高效能純前端線上音訊處理平台。它具備直觀流暢的波形視覺化介面、多軌混音編輯、智慧片段尋找，並全新導入了 **.arm / .amr 音檔解碼支援** 與 **全方位音訊檔案檢查與修復系統**。

---

## 🌟 核心功能

### 1. 廣泛音訊格式支援（含 .arm / .amr）
* **原生與專屬解碼器結合**：
  * **.arm / .amr 支援**：內建專屬 AMR (Adaptive Multi-Rate) 語音解碼引擎，完美解析手機錄音、通話紀錄與語音訊息等格式。
  * **常見格式支援**：MP3, WAV, AAC, M4A, FLAC, OGG 以及 MP4 (音訊提取)。
  * **容錯載入機制**：檔案解碼遇阻時自動啟動容錯修復管線，智慧診斷並修復標頭後再度嘗試解碼。

### 2. 專業音檔檢查與修復系統 (Audio Diagnostics & Repair)
* **二進位與容器層級修復**：
  * **WAV / RIFF 標頭修復**：修復因錄音異常中斷或程式崩潰導致的 `ChunkSize` 與 `data` 區塊長度為 0 或不符問題，重建合規的 RIFF 結構。
  * **AMR / ARM 標頭補全**：自動偵測無檔頭的 Raw AMR 音訊串流，智慧補齊標準 `#!AMR\n` 魔術字節。
  * **MP3 垃圾字元剝離**：移除檔案開頭損壞的無效位元組，精確對齊至首個合法的 MPEG 音訊同步幀 (Frame Sync)。
* **波形與訊號品質修復**：
  * **直流偏移消除 (DC Offset Removal)**：偵測訊號中軸偏移，自動歸零修正，消除剪輯爆音並釋放動態範圍。
  * **削波失真抑制 (Anti-Clipping)**：偵測過載峰值，透過軟拐點限制器 (Soft Limiter) 與安全增益校準，消除破音刺耳感。
  * **響度標準化 (Peak Normalization)**：針對錄音音量過低問題，提供一鍵標準化至 95% (-0.45 dB)。
  * **首尾冗餘靜音裁切**：智慧偵測開頭與結尾的無效死寂靜音並予以去除。
* **獨立「音檔檢查修復中心」Modal**：
  * 支援直接檢查「當前編輯音軌」或拖曳上傳「本機任何音訊檔案」進行全方位健康體檢。
  * 提供即時狀態燈號（健康、警告、損壞）、詳細診斷項目與修復日誌歷程。
  * 修復完成後可選擇「直接載入至主編輯器」或「下載修復後的 WAV 檔案」。

### 3. 實時波形視覺化與互動
* **雙軌 Canvas 高流暢度渲染**：主音軌與混音軌垂直對齊，支援滾輪縮放與時間軸平移。
* **混音疊加預覽**：開啟「顯示混音」可將混音軌片段以半透明方式同步疊加至主音軌波形上。
* **橘色定位游標**：點擊音軌顯示時間游標，支援鍵盤方向鍵即時微調。
* **即時頻率預估 (Hz)**：游標懸停波形時動態分析並提示對應頻率。

### 4. 智慧搜尋與特徵標記 (Smart Find)
* **多維度自動偵測**：支援依「音量大小 (Volume)」或「音訊頻率 (Frequency)」自動掃描音軌。
* **視覺化綠色標記**：搜尋結果即時呈現於波形上，支援「上一段 / 下一段」快速跳轉。
* **全目標顯示切換**：可一鍵切換顯示所有符合目標或專注單一選區。

### 5. 強大音訊剪輯操作
* **提取 (Extract)**：將選取範圍提取並命名保存至片段庫。
* **音量增強 (Amplify)**：自訂增益倍率調整選區音量。
* **剪除 (Cutout)**：移除選取範圍並自動拼接前後音訊。
* **保留 (Keep)**：僅保留選取範圍，修剪多餘前後音訊。
* **全選 (Select All)**：一鍵選取整軌音訊。
* **診斷修復 (Diagnostics)**：工具列直覺開啟音質與標頭修復工具。

### 6. 多層級復原機制 (Undo / Redo)
* 完整支援多層級復原 (`Ctrl+Z`) 與重做 (`Ctrl+Y`)，防止誤操作遺失工作進度。

### 7. 片段庫管理與多軌混音
* **彈出式片段清單 (Clips Panel)**：透過快捷鍵（預設為 `x`）隨時開啟與收合，釋放編輯空間。
* **片段獨立編輯 (ClipEditorModal)**：針對個別片段微調剪裁起訖點與增益。
* **混音軌排列與安插**：自訂各片段安插之精確時間點，支援多片段同時合成。

### 8. 專業多格式匯出 (Audio Export)
* 支援匯出整個音軌或當前選取範圍。
* 支援混音軌合併後匯出。
* 輸出格式支援：
  * **WAV**：無損 16-bit PCM 高品質音訊。
  * **MP3**：高效壓縮格式（基於 LAME 編碼）。

### 9. 個人化設定與行動裝置優化
* **自訂快捷鍵**：可自由配置播放、預覽、提取、剪除、保留、倍速切換等快捷熱鍵。
* **行動模式 Modal 介面**：針對窄螢幕將操作按鈕與搜尋欄位彈出化，手機與平板也能流暢剪輯。
* **微調步長調整**：自訂方向鍵微調跳轉秒數。
* **設定持久化**：自動儲存至 LocalStorage，並具備深層合併防覆蓋保護。

## ⌨️ 預設快捷鍵

| 快捷鍵 | 功能描述 |
| :--- | :--- |
| `空白鍵 (Space)` | 播放 / 暫停主音軌選區 |
| `x` | 開啟 / 關閉右側片段列表視窗 |
| `Ctrl + Z` | 復原上一步 (Undo) |
| `Ctrl + Y` | 重做下一步 (Redo) |
| `← / →` | 微調播放與選取游標位置（暫停時） |
| `1` | 切換為 1.0x 正常倍速播放 |
| `2` | 切換為 1.5x 加速播放 |
| `3` | 切換為 2.0x 快速播放 |

## 🚀 快速開始

### 環境需求
* **Node.js**：建議 v18 以上
* **pnpm**：建議 v9 或 v10（專案採用 `packageManager: pnpm`）

### 安裝步驟
1. 複製專案庫：
   ```bash
   git clone <repository-url>
   cd SoundCut
   ```

2. 安裝相依套件：
   ```bash
   pnpm install
   ```

3. 啟動開發伺服器：
   ```bash
   pnpm run dev
   ```

4. 建置生產版本：
   ```bash
   pnpm run build
   ```

## 🛠 關鍵技術與架構

* **核心框架**：React 19 + TypeScript
* **狀態管理**：Zustand 5（支援 LocalStorage 深度合併持久化與 History 狀態棧）
* **樣式與介面**：TailwindCSS + Lucide React 圖示庫
* **音訊核心**：Web Audio API (AudioContext, AudioBuffer, BufferSource)
* **專屬解碼**：BenzAMRRecorder（AMR-NB / ARM 語音前端解碼引擎）
* **音訊編碼**：lamejs (MP3 純前端編碼) + 原生 DataView (WAV PCM 封裝)
* **診斷修復引擎**：自研 `audioDiagnostics` 與 `amrDecoder` 二進位修復器
